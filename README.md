## 🚀 我正在做的

### ⚡ cc-switch 增强版 —— AI 编程助手统一控制面

基于 [farion1231/cc-switch](https://github.com/farion1231/cc-switch)（12.6w+ ⭐）深度魔改的 fork，一个桌面端搞定 **Claude Code / Codex / OpenCode / OpenClaw / Grok Build / Hermes Agent** 的配置管理：

| 能力 | 说明 |
|---|---|
| 🖥️ SSH 远程控制面 | 远端 `settings.json` 读写、MCP / Prompts / Skills / Sessions 远端管理 |
| 🐳 Docker 目标 | 直接管理容器内的 Agent 环境 |
| 🎯 桌面悬浮球 | 全局快速切换，不打断工作流 |
| ✅ 上游功能零丢失 | 本机原生功能完整保留，魔改只是叠加层 |

> 技术栈：Rust · TypeScript · Tauri 2 · React
